Unit 4 Review: Quadratic Functions

Practice set · Show all work · Due Friday
  1. Find the vertex of f(x) = 2x² − 12x + 7 by completing the square.
    f(x) = 2(x − 3)² − 11, so the vertex is (3, −11)
  2. Solve x² + 5x − 14 = 0 by factoring.
    (x + 7)(x − 2) = 0 → x = −7 or x = 2
  3. Use the quadratic formula to solve 3x² − 4x − 2 = 0. Round to the nearest hundredth.
    x = (4 ± √40) / 6 → x ≈ 1.72 or x ≈ −0.39
  4. A ball is thrown upward and its height is h(t) = −16t² + 48t + 5. When does it reach its maximum height, and what is that height?
  5. Write the equation of a parabola with vertex (−2, 4) that passes through (0, 12).
  6. Determine the number of real solutions of 4x² − 4x + 1 = 0 using the discriminant.
  7. Graph y = −(x − 1)² + 9. Label the vertex, axis of symmetry, and x-intercepts.
